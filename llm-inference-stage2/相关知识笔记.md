## Attention、MHA、MQA 与 GQA

### 1. 缩放点积注意力 (Scaled Dot-Product Attention)

#### 1.1 检索体系与张量定义

Self-Attention 将上下文融合建模为一种软寻址信息检索过程：

* **Query ($Q$)**：当前 Token 发出的查询向量（“在找什么”）。
* **Key ($K$)**：各候选 Token 的索引标签（“包含什么特性”）。
* **Value ($V$)**：各候选 Token 蕴含的实际语义表征（“具体内容”）。

#### 1.2 计算拓扑与张量维度变换

设定全局超参数：

* $B$：Batch Size（批大小）
* $T$：Sequence Length（序列长度）
* $d$：输入特征隐藏层维度 (Hidden Size)
* $d_k$：Query / Key / Value 的投影特征维度

```text
输入 X [B, T, d]
   │
   ├─► 线性投影 (W_Q, W_K, W_V) ──► Q, K, V ∈ [B, T, d_k]
   │
   ├─► 点积打分: S = (Q @ K^T) / sqrt(d_k) ──► S ∈ [B, T, T]
   │
   ├─► 归一化权重: A = Softmax(S, dim=-1) ──► A ∈ [B, T, T]
   │
   └─► 加权聚合: O = A @ V ──► O ∈ [B, T, d_k]

```

##### 各计算步公式与张量形状推演：

1. **线性投影 (Linear Projection)**

$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$


* 权重矩阵：$W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$
* 输出形状：$Q, K, V \in \mathbb{R}^{B \times T \times d_k}$


2. **打分矩阵计算 (Scaled Dot-Product)**

$$S = \frac{Q K^\top}{\sqrt{d_k}}$$


* 维度契合：$[B, T, d_k] \times [B, d_k, T] \longrightarrow [B, T, T]$
* 元素含义：$S_{i, j}$ 表示第 $i$ 个 Token 的 Query 与第 $j$ 个 Token 的 Key 的匹配相关度。


3. **注意力权重归一化 (Softmax)**

$$A = \operatorname{softmax}(S, \text{dim}=-1) \in \mathbb{R}^{B \times T \times T}$$


* 按行归一化，使得每个 Token 对全序列的注意力权重和严格为 $1$：$\sum_{j=1}^T A_{i, j} = 1$。


4. **值向量加权聚合 (Context Aggregation)**

$$O = A V$$


* 维度契合：$[B, T, T] \times [B, T, d_k] \longrightarrow [B, T, d_k]$


#### 1.3 缩放因子 $\sqrt{d_k}$ 的严密数学证明

##### 理论假设

假设向量 $q, k \in \mathbb{R}^{d_k}$ 的各个维度分量 $q_i, k_i$ 是**相互独立**的随机变量（随机初始化状态下不同投影方向不相关），且满足零均值、单位方差：


$$\mathbb{E}[q_i] = 0, \quad \operatorname{Var}(q_i) = 1$$

$$\mathbb{E}[k_i] = 0, \quad \operatorname{Var}(k_i) = 1$$

##### 均值推导

对于点积 $z = q \cdot k = \sum_{i=1}^{d_k} q_i k_i$：


$$\mathbb{E}[z] = \sum_{i=1}^{d_k} \mathbb{E}[q_i k_i]$$


根据独立变量性质，协方差 $\operatorname{Cov}(q_i, k_i) = 0$：


$$\mathbb{E}[q_i k_i] = \operatorname{Cov}(q_i, k_i) + \mathbb{E}[q_i]\mathbb{E}[k_i] = 0 + 0 \times 0 = 0 \implies \mathbb{E}[z] = 0$$

> **关键澄清（反例辨析）**：
> 若 $q$ 与 $k$ **强相关甚至完全一致**（如训练收敛后 $Q$ 成功匹配目标 $K$），则 $\operatorname{Cov}(q_i, k_i) = 1$，此时 $\mathbb{E}[q_i k_i] = \mathbb{E}[q_i^2] = \operatorname{Var}(q_i) + (\mathbb{E}[q_i])^2 = 1 + 0 = 1$。此时点积均值为 $d_k > 0$，注意力权重正向放大。独立假设是针对未缩放前的分布尺度评估。

##### 方差推导

计算单个分量乘积项的方差：


$$\operatorname{Var}(q_i k_i) = \mathbb{E}[(q_i k_i)^2] - (\mathbb{E}[q_i k_i])^2 = \mathbb{E}[q_i^2] \mathbb{E}[k_i^2] - 0 = 1 \times 1 = 1$$


对于独立随机变量和，方差具有可加性：


$$\operatorname{Var}(z) = \operatorname{Var}\left(\sum_{i=1}^{d_k} q_i k_i\right) = \sum_{i=1}^{d_k} \operatorname{Var}(q_i k_i) = d_k$$


点积的标准差为 $\sigma = \sqrt{\operatorname{Var}(z)} = \sqrt{d_k}$。

##### 缩放归一

根据方差缩放性质 $\operatorname{Var}(c X) = c^2 \operatorname{Var}(X)$，令常数 $c = \frac{1}{\sqrt{d_k}}$：


$$\operatorname{Var}\left(\frac{z}{\sqrt{d_k}}\right) = \left(\frac{1}{\sqrt{d_k}}\right)^2 \operatorname{Var}(z) = \frac{1}{d_k} \cdot d_k = 1$$


**结论**：除以 $\sqrt{d_k}$ 能将打分矩阵各元素的方差恒定锚定在 $1$ 附近，与特征维度 $d_k$ 解耦。


#### 1.4 Softmax 饱和与梯度消失分析

当 $d_k$ 较大（如 $d_k = 128$ 时，标准差 $\sigma \approx 11.3$）且未进行缩放时，点积结果的动态范围会被极度拉宽，矩阵中容易出现相差悬殊的极大值与极小值（如 $+30$ 与 $-30$）。

##### 带来的两大致命后果：

1. **注意力过早坍缩 (Hard Attention)**：

$$\operatorname{softmax}([+30, -30]) \approx [1.0, 0.0]$$

模型输出退化为接近 One-hot 的极值分布，丧失对上下文的多角度软加权汲取能力。

2. **反向传播梯度消失 (Gradient Vanishing)**：
Softmax 对输入第 $i$ 维的导数矩阵为：

$$\frac{\partial p_i}{\partial z_j} = p_i (\delta_{ij} - p_j)$$


当 $p_i \to 1$ 或 $p_i \to 0$ 时，导数项 $p_i(1 - p_i) \to 0$。由链式法则回传的梯度在流经 Softmax 时将被乘以极小值，前序投影参数（$W_Q, W_K$）的更新彻底停滞。


### 2. 多头注意力 (Multi-Head Attention, MHA)

#### 2.1 动机：打破单头 Softmax 的非线性表达瓶颈

在单头注意力机制中，针对同一 Token 只能生成**唯一一组**加和为 $1$ 的归一化概率分布。

* **语言的多义与多重关联性**：句子中的某个代词（如“他”）在同一位置往往同时承担**指代关系**（指代前文实体）、**句法搭配**（动宾关联）以及**邻近语法约束**。
* **单 Softmax 互斥冲突**：若模型将 $0.8$ 的权重分配给指代词，则仅剩 $0.2$ 的权重兼顾其他句法模式。
* **多头本质**：派生出 $h$ 个独立的子空间，分别运行各自的 Softmax 归一化，实现同一抽象层级下多种语义关系的同时提取。


#### 2.2 矩阵维度推导与显式换位 (Transpose)

设定总隐藏层维度为 $d$，头数为 $h$，每个头的特征维度为 $d_k = \frac{d}{h}$。

```text
输入 X: [B, T, d]
   │
   ├─► 线性投影: W_Q, W_K, W_V ∈ [d, d] ──► Q, K, V ∈ [B, T, d]
   │
   ├─► Reshape:  [B, T, d] ───────────────► [B, T, h, d_k]
   │
   ├─► Transpose: (1, 2) 维对调 ──────────► [B, h, T, d_k]
   │
   ├─► 并行注意力: (Q @ K^T) / sqrt(d_k) ──► S ∈ [B, h, T, T] ──► A ∈ [B, h, T, T]
   │                                     O_heads = A @ V ∈ [B, h, T, d_k]
   │
   ├─► Transpose: (1, 2) 维还原 ──────────► [B, T, h, d_k]
   │
   ├─► Reshape (Concat): ────────────────► [B, T, d]
   │
   └─► 融合投影: 乘 W_O ∈ [d, d] ────────► Output ∈ [B, T, d]

```

##### 为什么必须将形状从 $[B, T, h, d_k]$ 转置为 $[B, h, T, d_k]$？

* **GPU 批矩阵乘 (Batched MatMul) 规约**：CUDA / cuBLAS 算子（及 PyTorch 中的 `@` / `bmm`）默认**仅对张量的最后两个维度**执行 2D 矩阵乘法，而将前面所有维度均视作并行批次处理。
* **错误形状后果**：若保持 $[B, T, h, d_k]$，最后两维为 $h \times d_k$，矩阵乘法将演变成“头”与“头内维度”之间的非物理运算，破坏序列交互。
* **转置意义**：将维度变为 $[B, h, T, d_k]$ 后，批次前置为 $(B, h)$，最后两维为 $T \times d_k$。此时直接计算 $Q K^\top$：

$$[B, h, T, d_k] \times [B, h, d_k, T] \longrightarrow [B, h, T, T]$$


使得 GPU 能够并行、独立地在各头内部计算序列长度为 $T$ 的全量注意力矩阵。


#### 2.3 输出投影矩阵 $W_O$ 的本质与 MLP 的分工对比

多头拼接后得到的张量为：


$$\text{Concat} = [O_1, O_2, \dots, O_h] \in \mathbb{R}^{B \times T \times d}$$


紧随其后必须右乘输出矩阵 $W_O \in \mathbb{R}^{d \times d}$：


$$\text{Output} = \text{Concat} \cdot W_O$$

##### $W_O$ 与 MLP 的底层机制对比：

| 算子类别 | 输出投影层 $W_O$ | 多层感知机 MLP (或 SwiGLU) |
| --- | --- | --- |
| **计算形式** | $\text{Concat} \cdot W_O$（**纯线性映射**） | $\text{Activation}(X W_1) W_2$（**非线性升降维**） |
| **通道交互** | **跨头物理隔离打破器**：拼合后的前 $d_k$ 维仅含 Head 1 信息，后 $d_k$ 维仅含 Head 2 信息。$W_O$ 促使各头特征发生线性重组与混合。 | **单 Token 内部深度加工**：不改变序列跨度，通过升维至 $4d$ 及非线性激活形成类似于“记忆库 (KV Memory)”的事实提取。 |
| **跨 Token 交互** | 无（仅整合当前 Token 内部已聚合好的跨头特征） | 无（每个 Token 独立变换） |


#### 2.4 架构认知：多头（Width）vs 多层（Depth）

**多头注意力（Width / 并行视角）**：
* **物理定位**：同一语义抽象层级下的**横向并行切片**。
* **作用逻辑**：在当前层次上，允许单个 Token 同时与多个不同语境目标建立强连接（如同时锁定主语、谓语和连词）。


**多层网络（Depth / 递进流水线）**：
* **物理定位**：特征表示的**纵向层次抽象与推理链**。
* **作用逻辑**：底层抽取局部词性与语法构词；中层完成依存句法与指代消解；顶层构建高阶上下文语义与逻辑推理。


### 3. KV Cache 优化变体：MQA 与 GQA

#### 3.1 动机：Decode 的访存带宽瓶颈

在 Decode 阶段，每次生成新 Token 时，模型需利用当前 Token 的 Query 计算与历史上所有已生成 Token 的关联度。为避免 $O(T^2)$ 重复前向计算，必须将历史 Token 的 Key 和 Value 保存在显存中，即 **KV Cache**。

#### 硬件瓶颈痛点：

* 在标准 MHA 架构下，每个注意力头均拥有一套独立的 $K$ 和 $V$。
* Decode 阶段计算算术强度极低（每个请求每步仅处理 1 个 Token），GPU 计算单元大量闲置，整体耗时受限于**从显存向片上读取庞大 KV Cache 的显存带宽（Memory-Bound）**。
* 当并发数（Batch Size）和上下文长度（$T$）增加时，KV Cache 的显存占用迅速反超模型本体权重，导致吞吐量受限甚至显存溢出 (OOM)。


#### 3.2 MHA、MQA、GQA 结构对比与广播计算

设定 Query 头数为 $h$，特征维度为 $d_k$：

```text
MHA (Multi-Head Attention):
  Q Heads:  [ Q1 ]  [ Q2 ]  [ Q3 ]  [ Q4 ]  [ Q5 ]  [ Q6 ]  [ Q7 ]  [ Q8 ]
  KV Heads: [KV1 ]  [KV2 ]  [KV3 ]  [KV4 ]  [KV5 ]  [KV6 ]  [KV7 ]  [KV8 ]  (1 对 1)

MQA (Multi-Query Attention):
  Q Heads:  [ Q1 ]  [ Q2 ]  [ Q3 ]  [ Q4 ]  [ Q5 ]  [ Q6 ]  [ Q7 ]  [ Q8 ]
  KV Heads: └─────────────────────────[KV1 ]───────────────────────────┘  (8 对 1)

GQA (Grouped-Query Attention):
  Q Heads:  [ Q1 ]  [ Q2 ]  [ Q3 ]  [ Q4 ]  |  [ Q5 ]  [ Q6 ]  [ Q7 ]  [ Q8 ]
  KV Heads: └─────────[KV1 ]─────────────┘  |  └─────────[KV2 ]─────────────┘  (4 对 1)

```

##### 张量维度对比表：

| 机制类型 | Query 头数 ($h_Q$) | KV 头数 ($h_{KV}$) | $Q$ 张量形状 | $K, V$ 张量形状 |
| --- | --- | --- | --- | --- |
| **MHA** | $h$ | $h$ | $[B, h, T, d_k]$ | $[B, \mathbf{h}, T, d_k]$ |
| **MQA** | $h$ | $1$ | $[B, h, T, d_k]$ | $[B, \mathbf{1}, T, d_k]$ |
| **GQA** | $h$ | $g \ (1 < g < h)$ | $[B, h, T, d_k]$ | $[B, \mathbf{g}, T, d_k]$ |

##### 广播计算机制 (Broadcasting / Repeat)

在计算 $S = \frac{Q K^\top}{\sqrt{d_k}}$ 时，由于维度必须匹配：

* **MQA**：$K, V$ 张量形状为 $[B, 1, T, d_k]$，在计算过程中沿着第 1 维（头数维度）**广播（Broadcast）$h$ 次**，使得所有 $Q$ 头均与同一份 $K, V$ 计算点积。
* **GQA**：将 $h_Q$ 个头均匀划分为 $g$ 个组，每组包含 $\frac{h_Q}{g}$ 个 Query 头。第 $i$ 组的所有 Query 头共享第 $i$ 个 $KV$ 头。在计算时，组内按倍数进行头维度的广播对齐。

---

#### 3.3 KV Cache 显存占用定量推导

##### 通用显存计算公式

对于拥有 $L$ 层 Transformer、序列长度为 $T$、并发请求数为 $B$、采用 16-bit 浮点数（FP16/BF16，占 2 字节）的模型，其全局 KV Cache 显存容量为：


$$\text{Memory}_{KV} = 2 \times L \times B \times h_{KV} \times T \times d_k \times 2 \text{ Bytes}$$

* **项拆解**：
* 第一个 $2$：同时存储 Key 和 Value 两组张量。
* $h_{KV}$：实际保存的 KV 头数。
* 最后一个 $2$：单精度半字长（2 Bytes / element）。



##### 实例计算：Llama-3-8B 规模参数推演

* 参数配置：层数 $L = 32$，隐藏维度 $d = 4096$，Query 头数 $h_Q = 32$，头维度 $d_k = 128$。
* 单 Token 每一层所需的 KV Cache 显存计算：

$$\text{Per-Token-Layer} = 2 \times h_{KV} \times 128 \times 2 \text{ Bytes} = 512 \times h_{KV} \text{ Bytes}$$



1. **若配置为 MHA ($h_{KV} = 32$)**：

$$\text{Memory} = 512 \times 32 = 16,384 \text{ Bytes} = \mathbf{16 \text{ KB / token / layer}}$$


2. **若配置为 MQA ($h_{KV} = 1$)**：

$$\text{Memory} = 512 \times 1 = 512 \text{ Bytes} = \mathbf{0.5 \text{ KB / token / layer}} \quad (\text{显存降至 } \frac{1}{32})$$


3. **若配置为 GQA ($h_{KV} = 8$, 即 8 组 KV)**：

$$\text{Memory} = 512 \times 8 = 4,096 \text{ Bytes} = \mathbf{4 \text{ KB / token / layer}} \quad (\text{显存降至 } \frac{1}{4})$$


#### 3.4 三者全维度对比总结

| 评估维度 | MHA (Multi-Head) | MQA (Multi-Query) | GQA (Grouped-Query) |
| --- | --- | --- | --- |
| **KV 头数比例** | $h_{KV} = h_Q$ | $h_{KV} = 1$ | $h_{KV} = g \ (1 < g < h_Q)$ |
| **KV Cache 显存相对比率** | $100\%$ (基准) | $\frac{1}{h}$ (极致压缩) | $\frac{g}{h}$ (适度压缩) |
| **Decode 阶段内存带宽需求** | 极高（受 IO 限制严重） | 极低（显存搬运量极少） | 较低（接近 MQA 级别吞吐） |
| **模型表征与生成质量** | 表现最优（基准） | 质量有明显退化/精度易损 | 表现与 MHA 几乎持平 |
| **业界主流代表模型** | Standard Transformer, Llama 1 | PaLM, Falcon | Llama 2 (70B), Llama 3, Mistral, Qwen 2 |

##### 结论性演进逻辑：

1. **MHA** 提供了最充裕的表达自由度，但在大规模长文本与高并发推理阶段受到显存带宽的严重制约。
2. **MQA** 将存储开销压至理论极限，但强制所有查询共享单一键值基底，削弱了模型的泛化拟合能力。
3. **GQA** 在性能与效率之间取得了最优帕累托平衡点（Pareto Optimal），仅保留少量 KV 组即可在保证模型精度几乎无损的同时，将 KV Cache 压缩数倍，已成为现代主流前沿开源大模型的标准架构配置。
